# 🛡️ Campus Guardian — Smart Campus Management System v2

**CampusGuardian** is a modern, web-based Smart Campus Management System designed to improve campus safety, streamline incident reporting, and make university life safer and more organized.

The platform aims to provide university students with a centralized system where they can report emergencies, submit complaints, monitor incident reports, and access essential campus safety resources through a user-friendly interface.

The project is being developed in multiple phases, starting with a static frontend UI and gradually evolving into a fully functional software system.

## 🎯 Project Objectives

- 🚨 Enable students to report campus emergencies quickly.
- 📝 Provide an organized complaint submission system.
- 📊 Display incident statistics through an interactive dashboard.
- 📋 Allow users to view and track submitted reports.
- 🛡️ Improve campus safety through centralized incident management.
- 📍 Integrate campus maps and emergency location tracking in future versions.
- 🤖 Explore AI/ML-based incident classification and priority detection.

## ✨ Current Features — Static UI

The initial version focuses on frontend design and user interface development using HTML and CSS.

- 🏠 **Home Page:** Overview of campus safety services and essential features.
- 📊 **Dashboard:** Statistics cards, visual charts, recent reports, and activity summaries.
- 🚨 **Emergency Report Page:** Emergency reporting interface with a prominent SOS button.
- 📝 **Complaint Submission:** Form interface for submitting campus-related complaints.
- 📋 **Report List:** Structured table for displaying incident reports and their statuses.
- 👤 **Student Profile:** User profile interface.
- 🔐 **Login Page:** User authentication interface.
- ✨ **Registration Page:** New student registration interface.
- 🎨 **Responsive Design:** A clean, modern interface featuring a dark navy sidebar, blue highlights, and white dashboard cards.

> **Note:** This is currently a static UI prototype. Forms, authentication, report submission, database operations, and other dynamic features are planned for future development.

## 🛠️ Technologies

### Currently Used
- HTML5
- CSS3

### Planned Technologies
- **JavaScript** — Interactive UI, form validation, dashboard functionality, and report filtering.
- **Node.js & Express.js** — Backend development and REST API creation.
- **MongoDB** — Database for storing user accounts, complaints, and incident reports.
- **Leaflet / Google Maps API** — Campus mapping and emergency location visualization.
- **AI/ML** — Automated incident classification and priority detection.
